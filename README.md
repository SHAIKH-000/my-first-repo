# 📊 Interactive Person Data Collection

A beginner-friendly interactive Python script designed to collect user input, perform type conversions, calculate approximate birth year, and display memory management details (Data Types & Memory Addresses).

---

## 📌 Project Overview

This script demonstrates fundamental Python concepts including:
- **User Input Handling:** Collecting data via `input()`.
- **Type Casting:** Converting strings to integers (`int()`) and floats (`float()`).
- **Basic Arithmetic:** Calculating the approximate birth year using current year logic.
- **Python Memory Management:** Inspecting data types using `type()` and memory locations using `id()`.

---

## 💻 Code Summary & Logic

1. **Input Collection:** Prompts the user for Name, Age, Height, and Favorite Number.
2. **Type Conversion:** Converts input string values into appropriate numeric types.
3. **Birth Year Calculation:** Computes approximate birth year using `current_year - age`.
4. **Memory & Type Inspection:** Displays the value, variable data type, and its memory address (`id()`).
